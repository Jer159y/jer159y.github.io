04 / READ THE FINE PRINT

선택의 근거와 남은 판단

CONTENT REVIEW · 2026.10.27
A

추천은 어떻게 바뀌나요?

목적별 필수 물리와 추가 선택을 합쳐 표현 불가능한 모델을 제외합니다. 남은 후보는 목적별 적합성, 상태의 단순성, QG의 Ro 점검으로 정렬합니다. 표시 순서는 설명 가능한 설계 판단이며, 정확도 확률이나 성능 benchmark가 아닙니다.

B

규모는 예시, 경계는 가정

km나 날짜만으로 모델이 결정되지는 않습니다. Rossby 수, 성층, 파장/수심, 경계와 원하는 출력이 함께 중요합니다. 화면의 시간 척도는 L/U와 L/√(gH)이며, 예보 가능 기간이나 수치 시간 간격 Δt를 뜻하지 않습니다.

C

현실 예측에는 무엇이 더 필요한가요?

수심·해안선, 초기장, 개방 경계, 바람·조석·열속, 마찰·혼합, 이산화·자료동화와 관측 검증이 필요합니다. 실험실은 이상화한 NS·SWE·QG를 수치 적분합니다. 실제 해역의 예보·자료동화·검증을 대신하지 않습니다.
